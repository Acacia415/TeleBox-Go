# eat 静态表情模板

`eat` 读取被回复用户的头像，`eat2` 读取被回复消息中的图片或贴纸；两条命令共用模板和合成流程。

模板配置包含底图 `url`、自己的头像区域 `me`、对方的头像区域 `you`。每个区域通过 `x`、`y` 定位，用蒙版 PNG 的尺寸决定头像大小、透明通道决定可见形状，还支持旋转、亮度和水平翻转。插件先裁剪缩放头像，再按蒙版合成到底图，最后输出不超过 512×512 的 WebP 贴纸。带 `stamp` 的模板则把图案作为印章叠加到目标图片。

远程配置由 `eat set [配置地址]` 更新；已有本地资源优先读取，缺少的资源从配置源下载并缓存。

## 看剑：kj

回复对方消息后发送 `-eat kj`，左侧剑客使用自己的头像，右侧女孩脸部使用被回复用户的头像。使用自定义命令前缀时，将 `-` 换成对应前缀。回复图片后发送 `-eat2 kj`，右侧改用该图片。

底图位于 `builtin/kanjian.png`，保留原始 512×512 透明画布。`builtin.go` 定义命令名、区域坐标和资源路径：

| 区域 | 左上角坐标 | 蒙版尺寸 | 保留的前景 |
| --- | --- | --- | --- |
| 自己（左） | (77, 193) | 101×100 | 手臂、拳头及头部外轮廓 |
| 对方（右） | (442, 265) | 38×45 | 帽子、头发及脸部外轮廓 |

底图和两张带抗锯齿透明边缘的蒙版位于 `builtin/`，通过 `go:embed` 打包进插件二进制。指定 `kj` 时直接使用内置模板，无需请求远程模板配置；加载或刷新远程列表时也会加入 `kj`，同名远程项使用内置定义。`eat clear` 不会删除内置资源。

`builtin_test.go` 验证左右头像来源、前景保留、WebP 输出，以及配置刷新和清理后的可用性。
